# Config

Tables and starting values kept out of code (server/spec.md §4). Loaded at start; `DEMO_MODE=1` applies `numbers.yaml` `demo:`.

| File | What |
| --- | --- |
| `numbers.yaml` | Every numeric starting value (+ demo overrides) |
| `label_table.yaml` | Product group → care / clue |
| `sensitive_words.yaml` | Masking safety net |
| `item_tasks.yaml` | Per-item tasks and their end rules |
| `holiday_calendar.yaml` | Dated holidays for find_time |
| `device_names.yaml` | Device type → Korean name |
| `card_templates.yaml` | Card sentences and line notes |
| `material_courses.yaml` | Material → styler course |
| `command_policy.yaml` | Commands allowed per way (safety) |
